## 服务器检查

- [ ] 在安装 .NET Hosting Bundle 之前已安装 IIS；存在 `AspNetCoreModuleV2`。
- [ ] WebPass 使用专用的低权限应用程序池身份。
- [ ] 站点具有 HTTPS 绑定且没有 HTTP 绑定。
- [ ] HTTPS 证书 SAN 包含客户端访问 IPv4 地址。
- [ ] 数据加密证书与 HTTPS 证书分离。
- [ ] 仅应用程序池身份和已批准的管理员能够读取数据证书私钥。
- [ ] Windows 防火墙仅允许来自已批准局域网 CIDR 的 TCP 443。
- [ ] WebPass 可在本机访问 SQL Server，局域网客户端无法访问。
- [ ] `/health` 仅返回应用程序/数据库可用性，不包含版本、路径、堆栈跟踪或异常详情。
- [ ] 重启服务器后，SQL Server、IIS、应用程序池和 `/health` 均可恢复，无需人工修复。

## 应用程序检查

- [ ] 未经身份验证的请求会通过 HTTPS 重定向到登录页。
- [ ] 登录锁定和登录请求限制符合规范。
- [ ] 普通用户无法打开管理员页面或密码导出功能。
- [ ] 不具有 `SecretReveal` 权限的用户无法显示密码。
- [ ] 重新验证在五分钟后过期，且绑定到当前会话。
- [ ] 显示的值会在 30 秒后从页面消失，响应为 `no-store`。
- [ ] 普通 CSV/XLSX 导出不包含密码或加密字段。
- [ ] 管理员密码导出仅限 XLSX、要求重新验证，并使用 `no-store`。
- [ ] 导入会以原子方式拒绝含有阻断性行错误的数据，且不会持久保存明文暂存数据。
- [ ] 变更状态的表单会拒绝缺失防伪令牌的请求。
- [ ] 响应包含预期的 CSP、`nosniff` 和 Referrer Policy 标头。
- [ ] 登录、重新验证、Ping、显示、导入、导出和管理操作都会生成已脱敏的审计记录。
