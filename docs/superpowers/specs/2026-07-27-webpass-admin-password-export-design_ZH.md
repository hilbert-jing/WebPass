# WebPass 安全导出和管理员密码导出设计

**日期：** 2026-07-27

## 背景

WebPass 已将服务器密码保存为由证书支持的 AES-GCM 信封，支持绑定到当前会话及用户行版本的五分钟当前密码重新验证授权，并会审计密码显示而不记录机密内容。

原“安全数据与运维”计划中的加密备份和恢复已移出范围。WebPass 改为需要不含机密的普通导出，以及独立的、仅管理员可用、包含已解密服务器密码的 XLSX 导出。

该应用是小型内部局域网工具。本设计优先考虑清晰的授权边界和可维护实现，而非附加备份、分发或企业合规功能。

## 目标

- 允许拥有 `ExportData` 的用户导出不含密码的筛选后资产清单。
- 普通无机密导出支持 CSV 和 XLSX。
- 提供独立的、仅管理员可用的 XLSX 服务器密码导出。
- 管理员密码导出前必须具有有效期五分钟的当前密码重新验证授权。
- 在内存中生成导出，不使用临时文件。
- 防止所有文本值被电子表格解释为公式。
- 审计导出操作，但不记录密码或加密材料。
- 复用现有清单筛选、管理员检查、重新验证授权、机密加密器和审计写入器。

## 不在范围内

- 数据库备份或恢复。
- 加密备份包和备份口令。
- 将导出文件作为恢复操作导入。
- 管理员密码导出的 CSV 或其他格式。
- 对 XLSX 文件本身进行密码保护或加密。
- 定期导出、后台作业、电子邮件投递或外部存储。
- 高并发压力测试或变更。

## 用户体验

### 普通导出

拥有 `ExportData` 的用户可看到 **导出** 导航项。页面提供现有资产清单筛选器以及 CSV 或 XLSX 选项。输出仅包含资产字段，绝不包含密码、密文、随机数、认证标签、封装密钥、密码哈希、会话数据或审计数据。

### 管理员密码导出

管理员会在管理区域看到独立的 **密码导出** 项。页面：

1. 显示警告：下载的工作簿包含明文服务器密码，必须据此妥善处理。
2. 接受与普通导出相同的资产清单筛选器。
3. 仅提供 XLSX。
4. 没有有效授权时重定向到现有当前密码重新验证流程。
5. 当前会话获得有效授权后启用导出。

五分钟授权可在其现有有效期内重复使用。本功能不引入第二种授权或新的密码验证机制。

## 授权边界

普通导出需要 `PermissionCode.ExportData`。

管理员密码导出必须同时满足：

- 用户已通过身份验证且已启用。
- `IsAdministratorAsync(userId)` 返回 `true`。
- `IReauthenticationGrantStore` 中存在针对同一用户、当前身份验证会话指纹及当前用户行版本的有效条目。

管理员密码导出不依赖 `ExportData` 或 `SecretReveal`。管理员状态和重新验证构成其明确边界，使敏感操作独立于普通的委派导出权限。

Razor Page 策略/处理程序和应用服务均会执行授权检查；直接调用服务不能绕过管理员或授权验证。

## 组件

### 无机密导出服务

`AssetExportService` 接受导出格式、`ServerListQuery`、操作者 ID 和取消令牌。它会验证 `ExportData`，复用活动服务器清单筛选语义，仅投影明确允许的资产字段，在内存中生成 CSV 或 XLSX，并写入不含机密的摘要审计。

查询不得联接或加载 `ServerSecrets`、`DataEncryptionKeys`、用户、会话、哈希或审计日志。

### 管理员密码导出服务

`AdministratorPasswordExportService` 接受 `ServerListQuery`、管理员 ID 和取消令牌。它会验证管理员身份、根据当前会话和用户行版本验证现有重新验证授权、加载筛选后的活动资产及可选 `ServerSecret`、通过 `ISecretCipher` 解密每个可用密码、在内存中生成一个 XLSX 工作簿，并为成功或失败写入无机密摘要审计。

没有已存储密码的资产生成空密码单元格。机密解密失败会中止整个下载；WebPass 不返回部分工作簿。

### 电子表格净化器

所有来自存储或用户输入数据的字符串单元格均通过一个共享净化器。以 `=`、`+`、`-` 或 `@` 开头的值，在写入 CSV 或 XLSX 前加上撇号。

密码列使用同一净化器，因此密码不能成为公式。显示的密码仍包含原始值，而不是将其作为电子表格内容执行。

## 导出列

普通 CSV 和 XLSX 包含：

1. `BusinessIp`
2. `Location`
3. `AliveStatus`
4. `ComputerName`
5. `SystemName`
6. `OperatingSystemVersion`
7. `DatabaseVersion`
8. `Notes`

管理员密码 XLSX 包含相同列，另加：

9. `Password`

不导出内部 ID、行版本、子网 ID、用户 ID 或加密字段。

## 数据和内存流

服务从 SQL Server 获取筛选后的行，在应用内存中创建工作簿或 CSV 流，并将完整字节内容返回 Razor Page。不会写入临时或暂存文件。

对于密码导出，明文只在构建工作簿时存在于本地操作作用域和返回的下载字节中；不会存入应用状态、TempData、日志、异常或审计负载。

下载响应使用附件处置以及阻止浏览器和代理缓存的标头，包括 `Cache-Control: no-store`。

## 审计事件

普通导出写入一个 `AssetExport` 审计事件，包含结果、格式、已应用筛选器和导出行数。管理员密码导出写入一个 `AdministratorPasswordExport` 事件，包含结果、固定为 `Xlsx` 的格式、已应用筛选器和导出行数。

审计负载绝不包含导出行、服务器密码、密文、加密密钥材料或可能含机密数据的异常详情。被拒绝和失败的管理员密码导出尝试同样会被审计。

## 错误处理

- 缺少 `ExportData` 时，普通导出返回授权拒绝。
- 非管理员在加载任何机密前收到授权拒绝。
- 缺少或过期的重新验证授权会重定向至现有重新验证页，且不生成文件。
- 无效筛选器使用现有安全验证行为。
- 生成或解密错误不返回文件，并记录不含机密的失败审计。
- 取消会停止生成，且不写入成功审计。

## 数据库影响

不需要实体、表、列、索引或 EF Core 迁移。

## 测试策略

单元测试覆盖电子表格公式净化、普通与管理员导出的精确列集合，以及无机密资产的空密码单元格。

集成测试覆盖：普通 CSV/XLSX 不含密码或加密列、普通导出需要 `ExportData`、非管理员不能访问密码导出、无有效重新验证授权的管理员不能导出密码、当前会话授权可启用密码 XLSX 导出、其他会话或过期用户行版本授权会被拒绝、密码 XLSX 含已解密密码且无加密字段、密码形式的公式被转义、审计事件只含格式/筛选器/结果/行数、解密失败不产生部分下载，以及下载响应使用 `no-store`。

现有完整 Release 测试套件仍是身份验证、授权、审计、资产管理、密码显示和导入行为的回归门槛。

## 风险和边界

管理员 XLSX 在下载后有意包含明文密码。WebPass 可以限制创建和浏览器缓存，但无法控制管理员如何保存或共享下载文件。UI 警告和审计事件明确说明该边界。

工作簿加密、文档权限管理、下载生命周期跟踪和数据泄露防护集成可作为未来措施，但不属于已批准的局域网范围，且不会实施。
