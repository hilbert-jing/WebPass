# WebPass 安全数据操作实施计划

> **面向代理式执行人员：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans，按任务逐项实施本计划；步骤使用 `- [ ]` 复选框跟踪。

**目标：** 在已完成的核心平台上增加服务器密码加密与显示、安全导入/导出（包括经独立重新验证的管理员密码 XLSX）以及 IIS 生产加固。

**架构：** 应用保持为单个 ASP.NET Core 10 应用程序。带版本的 AES 数据密钥由 Windows 证书封装；密码显示需要服务器端重新验证授权；导入的密码在保留预览状态前即被加密。IIS 是 HTTPS 边界，SQL Server 始终仅部署在服务器本机。

**技术栈：** .NET 10、ASP.NET Core、X.509 Windows 证书存储、AES-GCM、Argon2id、SQL Server 2025 Express、ClosedXML、xUnit。

## 全局约束

- 密码、明文、密文、随机数、认证标签、封装密钥、密码哈希、会话和认证材料均不得写入审计、日志、异常、TempData 或普通导出。
- HTTPS 证书与数据加密证书必须独立；后者仅用于封装数据密钥。
- 密码显示和管理员密码导出均须针对当前会话、当前用户行版本的五分钟重新验证授权。
- 所有导入、导出和工作簿构建均在内存中完成，不创建明文暂存文件。
- 文本电子表格值必须防公式注入；导出下载使用 `no-store`。
- SQL Server 不暴露给局域网；IIS 仅提供 HTTPS。
- 每项任务遵循 TDD 并以聚焦提交结束。

## 文件结构

- `Domain/Entities`：加密密钥、服务器机密及其版本化关联。
- `Application/Secrets`：密封、解封、轮换、重新验证和密码显示。
- `Application/Import`、`Application/Export`：内存导入/导出模型、验证和写入器。
- `Infrastructure/Secrets`：Windows 证书、AES-GCM、授权和审计集成。
- `Pages`：密码显示、导入、普通导出和管理员密码导出页面。

### 任务 1：添加证书支持的信封加密和密钥轮换

创建版本化数据密钥和服务器机密实体、迁移、`ISecretCipher`、证书密钥封装器及测试。每个服务器密码使用独立 AES-GCM 加密；AES 数据密钥使用 `LocalMachine\My` 的 RSA 数据加密证书封装。加密材料带版本，便于密钥轮换。任何缺失证书、证书私钥不可读或解密失败必须安全失败，且不泄漏机密。

### 任务 2：添加重新验证和短时密码显示

创建 `IReauthenticationGrantStore`、当前密码验证流程和密码显示服务/页面。授权必须绑定用户、当前身份验证会话指纹和用户行版本，并在五分钟后过期。只有具有 `SecretReveal` 的用户且具有有效授权时才能显示；显示值仅存在于响应范围，页面在 30 秒后清除，并以 `Cache-Control: no-store` 返回。每次允许、拒绝及失败均记录无机密审计。

### 任务 3：添加加密创建/编辑和仅内存 Excel/CSV 导入

资产创建和编辑接受可选密码，但在持久化前立即通过机密加密器处理。导入支持 Excel/CSV，进行列、类型、CIDR、重复 IP 和权限验证；含阻断性行错误时原子性拒绝，不持久保存明文预览或暂存数据。应用批准后才写入资产和加密机密，并审计汇总结果。

### 任务 4：添加无机密普通导出和管理员密码 XLSX 导出

#### 任务 4.1：添加导出模型、净化器和内存文档写入器

共享电子表格净化器会在以 `=`、`+`、`-` 或 `@` 开头的文本前添加撇号，防止 CSV/XLSX 公式注入。文档在内存中构建，下载数据不写临时文件。

#### 任务 4.2：添加无机密导出服务和页面

`ExportData` 用户可按现有清单筛选器导出 CSV 或 XLSX。输出仅包含明确允许的资产字段，查询不得加载机密、密钥、用户、会话、哈希或审计数据；成功/失败均记录仅含格式、筛选条件和行数的审计摘要。

#### 任务 4.3：添加经重新验证的管理员密码 XLSX

该功能仅限管理员，不依赖 `ExportData` 或 `SecretReveal`。它验证管理员身份和当前会话五分钟重新验证授权，加载筛选后的资产及可选机密、逐项解密并生成一个 XLSX 工作簿。无密码资产生成空单元格；任何解密失败都会中止整个下载，绝不返回部分文件。密码列同样使用公式净化器。

### 任务 5：加固生产托管并验证验收

部署 IIS 前后，验证独立 HTTPS/数据加密证书、仅 HTTPS 绑定、专用低权限应用程序池身份、私钥 ACL、受限 TCP 443 防火墙规则和本地 SQL Server。完成自动化测试、`/health` 检查和生产验收记录；不得启用详细错误或请求/响应正文日志。

## 自查

- 覆盖范围包括证书信封加密、密钥轮换、短期重新验证、密码显示、加密编辑、内存导入、无机密普通导出、管理员密码 XLSX 和 IIS 加固。
- 普通导出不含任何密码或加密字段；管理员密码 XLSX 必须经过管理员检查和当前会话重新验证。
- 机密在所有边界均不进入审计、日志、异常、临时文件或缓存。
