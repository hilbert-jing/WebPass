# WebPass v1.1.0 Usability Corrections Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Promote password reveal, safely expose the existing `Take` paging control, and add audited non-persistent Ping probes for unregistered subnet addresses.

**Architecture:** Keep password reveal and registered-server Ping contracts intact. Normalize list input at the Razor Page boundary, factor transport execution into a shared `PingService` core, and add a separate free-address service/page workflow that writes only `AuditLogs`.

**Tech Stack:** .NET 10, ASP.NET Core Razor Pages, EF Core 10, SQL Server/InMemory test providers, xUnit, vanilla JavaScript/CSS.

## Global Constraints

- Work only on `feature/v1.1.0-usability`; do not modify `main`.
- Do not change EF Core entities, `WebPassDbContext`, model snapshot, or migrations.
- Do not write free-address probes to `PingResults`, create assets, or change asset state.
- Do not modify `secret-reveal.js`, reauthentication, permissions, CSRF, or automatic secret hiding.
- Reuse `PingExecute`, configured timeout, concurrency gate, per-user allowance, `IPingTransport`, normalization, and `AuditWriter`.
- Keep changes limited to the three approved usability corrections.
- Keep English and Chinese design/plan documents side by side.

public async Task<IActionResult> OnPostPingFreeIpAsync(
