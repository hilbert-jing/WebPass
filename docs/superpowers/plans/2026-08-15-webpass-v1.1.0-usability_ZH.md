# WebPass v1.1.0 易用性修正实施计划

> **供代理执行者使用：** 必须使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans，逐任务实施本计划。步骤使用复选框（`- [ ]`）跟踪。

**目标：** 提升查看密码操作、安全开放现有 `Take` 分页控制，并为未登记子网地址增加有审计但不持久化到 Ping 历史的探测能力。

**架构：** 保持密码查看和已登记服务器 Ping 契约不变；在 Razor Page 边界规范化列表输入；在 `PingService` 中提取共享传输核心；新增只写 `AuditLogs` 的空闲地址服务与页面工作流。

**技术栈：** .NET 10、ASP.NET Core Razor Pages、EF Core 10、SQL Server/InMemory 测试提供程序、xUnit、原生 JavaScript/CSS。

## 全局约束

- 只在 `feature/v1.1.0-usability` 工作，不修改 `main`。
- 不修改 EF Core 实体、`WebPassDbContext`、模型快照或 migration。
- 空闲地址探测不得写入 `PingResults`、创建资产或修改资产状态。
- 不修改 `secret-reveal.js`、二次验证、权限、CSRF 或密码自动隐藏。
- 复用 `PingExecute`、配置超时、并发门、单用户额度、`IPingTransport`、结果规范化和 `AuditWriter`。
- 修改范围仅限三个已批准的易用性修正。
- 英文与中文设计/计划文档必须在同一目录并列保存。
